# Weather App 🌦️

A modern, responsive weather application built with Flutter that provides real-time updates, 7-day forecasts, and global location search.

## ✨ Features
- **Global Search**: Search for any city using the `geocoding` API.
- **Responsive Design**: Optimized for all Android screen sizes (phones and tablets).
- **Dark/Light Mode**: Seamless theme switching.
- **Detailed Forecasts**: Hourly and weekly breakdown of weather metrics.
- **Dynamic Themes**: UI colors change based on current weather conditions.

## 🛠️ Built With
- Flutter/Dart
- [Open-Meteo API](https://open-meteo.com/) (Weather data)
- Geocoding & Geolocator (Location services)

## 📦 How to Run
1. **Clone the repo**:
   ```bash
   git clone https://github.com/yourusername/weather_app.git
   ```
2. **Install dependencies**:
   ```bash
   flutter pub get
   ```
3. **Run the app**:
   ```bash
   flutter run
   ```
